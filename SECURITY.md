# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Security** tab and select **Report a vulnerability** when private
vulnerability reporting is available. Otherwise, contact the repository owner
through the contact information on their GitHub profile and request a private
reporting channel.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. Do not include real API keys, gateway tokens, or private
workspace data in the report.

You should receive an acknowledgement within seven days. A remediation timeline
will depend on severity and the complexity of the fix.
